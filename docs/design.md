# DeepScalper 复现设计文档

## 1. 概述

本项目在 A 股个股 3 秒级 tick 快照数据上复现论文《DeepScalper: A Risk-Aware
Reinforcement Learning Framework to Capture Fleeting Intraday Trading
Opportunities》（Sun et al., 2022）。复现覆盖论文四大组件：

1. **动作分支的 Dueling Q-Network（BDQ）**——价格 / 数量二维细粒度动作空间的高效优化；
2. **含 hindsight bonus 的奖励函数**——引导智能体以整日视角评估交易动作；
3. **多模态编码器-解码器市场嵌入**——微观（LOB + 私有状态，LSTM）与宏观（OHLCV + 技术指标，MLP）双路编码；
4. **风险感知辅助任务**——以未来波动率预测正则化市场嵌入。

实验标的为 301308（创业板）与 688030（科创板），数据区间 2026-02 至 2026-07。

## 2. 数据与窗口结构

### 2.1 数据

- 来源：`data/<code>/<code>.<EX>_<yyyymm>_tick.parquet`，月度文件，121 列，
  含 10 档盘口价量、各档委托笔数、撤单统计、加权均价、累计成交等。
- 过滤：仅保留 09:30–15:00 且 `LastPx > 0`、`Buy1Price > 0`、`Sell1Price > 0` 的快照，
  剔除盘前 / 盘后及无效行；日内按时间排序。连续竞价时段快照主体间隔为 3 秒。
- 规模：301308 与 688030 各 119 个交易日（分别约 4800 / 3200 快照/日）。

### 2.2 窗口参数（用户指定）

| 参数 | 值 | 含义 |
|---|---|---|
| 回看窗口 | 600 tick（约 30 分钟） | 状态输入长度 |
| hindsight 视野 h | 3600 tick = 180 决策步（约 3 小时） | 对齐论文最优 h=180（1 分钟/步），日尾截断 |
| 波动率标签窗口 | 300 tick（约 15 分钟） | 辅助任务回归目标 |
| 决策间隔 | 20 tick（约 60 秒） | 每 20 个快照决策一次 |
| 数据切分 | 7 : 1 : 2 | 按交易日时序切分训练 / 验证 / 测试 |

窗口不跨交易日：hindsight 与波动率标签在日尾截断；可跨午休（tick 序列在日内连续编号，
午休间隙不产生快照）。每个交易日的决策点为 `lookback-1, lookback-1+20, ...`（约 200 个/日）。

## 3. MDP 设计（论文 3.2 的 tick 适配）

### 3.1 状态

- **微观状态**：回看窗口内按 20 tick 抽样的 30 步盘口快照序列（50 维/步，见 4.1），
  与私有状态序列 `z_t = (pos_t/pos_max, cash_t/cash_0, 剩余时间比例)`（3 维/步）。
  私有状态在决策间隔内不变，序列中以当前值重复填充。
- **宏观状态**：回看窗口聚合为 30 根 20-tick OHLCV bar（基于中间价与成交量增量），
  按论文 Table 2 计算 11 个相对价格指标，并附加相对量能 `z_volume`，共 12 维。

### 3.2 动作

限价单二元组 `(p_offset, ±q)`，BDQ 两分支分别离散化：

- 价格分支：11 档偏移 `{-5, ..., +5} × 0.01 元`，基准为对手价（买单参考卖一价、
  卖单参考买一价）——买向偏移 ≥ 0 / 卖向偏移 ≤ 0 即穿价，反向为被动限价；
- 数量分支：9 档带符号数量 `{-50, -25, -10, -5, 0, 5, 10, 25, 50}`，0 表示不交易。

### 3.3 撮合模拟

限价相对对手价：买单限价 ≥ 卖一价则以卖一价成交，卖单限价 ≤ 买一价则以买一价成交；
未穿价不成交（即时撮合，不排队等待）。成交数量受最大持仓约束截断。日终以最后中间价
强制平仓（论文的日内不隔夜设定）。价格档取对手价基准而非中间价，是因为标的间价差
差异悬殊（301308 价差中位数约 11 个价位，688030 约 2 个）：固定中间价基准的档位
在宽价差标的上可能永远无法穿价，动作空间失效。

### 3.4 奖励

```
r_t = leverage × [(p_{t+1} − p_t)·pos_t − cost_t] / cash_0
r_hind_t = r_t + w · leverage · (p_{t+h} − p_t)·pos_t / cash_0   （仅训练使用）
```

其中 `p` 为决策点中间价，`pos_t` 为动作后的持仓；`cost_t` 为真实交易成本
（手续费 δ×成交额 + 半价差成本 |成交价 − 中间价|×成交数量），与现金账户记账
完全一致——当成交价等于中间价时退化为论文公式。δ = 2.5e-4（买卖双边，A 股
现实佣金口径），leverage = 1（论文为 5），w = 0.1（论文网格搜索最优值）。
测试期仅使用原始奖励 `r_t` 计算盈亏。

### 3.5 波动率标签

未来 300 tick（15 个决策步）内逐决策步中间价对数收益的标准差（日尾截断），
作为辅助任务回归目标。论文 4.4 的 `y_vol = σ(r)` 中 r 为「每个时间步」的收益，
时间步即决策步（论文 1 分钟）；σ(r) 与逐决策步收益同量级，这正是 η=1 有效的
量级依据（论文 6.4）。若按 3 秒 tick 收益计算，σ(r) 约小一个数量级，辅助任务
梯度会被 Q 损失淹没而失效。hindsight 视野（3600 tick）独立于该窗口。

## 4. 特征工程

### 4.1 微观特征（50 维/快照）

- **10 档盘口（40 维）**：各档价格 / 一档价格 − 1；数量取 `log1p(各档量 / 一档量)`
  （论文 5.4 的归一化方式，数量取 log1p 以稳定量纲）。
- **微观结构增强（10 维）**：相对价差、总量失衡、委托笔数失衡、加权买 / 卖均价相对值、
  撤单失衡、档位笔数失衡、`log1p(成交量增量)`、`log1p(成交笔数增量)`、中间价对数收益(bp)。

### 4.2 宏观特征（12 维/决策点）

按论文 Table 2：`z_open, z_high, z_low, z_close, z_adj_close`（个股无复权，`z_adj_close`
同 `z_close`）、`z_d_{5,10,15,20,25,30}`，附加 `z_volume`（当根 bar 量 / 窗口均量 − 1）。

### 4.3 标准化

全部输入特征先做无量纲化（比值 / 失衡 / 对数相对量），再叠加基于**训练集**拟合的
z-score 标准化（`fit_feature_stats`）：微观 50 维与宏观 12 维各自逐维减去训练均值、
除以训练标准差并截断至 ±10。验证 / 测试集复用训练统计量，无前视泄漏。
私有状态本身已归一（持仓 / 上限、现金 / 初值、剩余时间比例），不再变换。

## 5. 模型结构

```
微观序列 (30×50) ──LSTM(64)──┐
私有序列 (30×3)  ──LSTM(64)──┼─ concat ─► e_i (128) ─┐
宏观向量 (12)    ──MLP(64)───► e_a (64) ──────────────┼─ concat ─► e_t (192)
                                                       │
        ┌── trunk MLP(128) ──┬── V(s) (1)              │
        │                    ├── Adv_price (11)         ├── Q_price, Q_qty（dueling 聚合）
        │                    └── Adv_qty (9)            │
        └── vol_head: Linear(192→1) ──► 波动率预测 ŷ_vol
```

总损失 `L = L_q + η · L_vol`，η = 1.0；`L_q` 为两分支一步 TD 误差的加权均值
（PER 重要性采样权重），`L_vol` 为波动率预测 MSE。

## 6. 训练与评估

- 优化器 Adam(lr=1e-4)，γ = 0.99，batch 64，每 2 个决策步更新一次，目标网络每 500 次更新同步；
- 优先经验回放（proportional，α = 0.6，β 由 0.4 线性升至 1.0，容量 10 万）；
  转移以「交易日 id + 决策时刻 + 私有状态」轻量引用存储，采样时重建观测；
- ε-greedy（DS 系与 DQN 一致）：前 60% 训练轮次内由 1.0 线性退火至 0.1；
- 每 epoch 在验证集以贪心策略评估 TR，保存验证最优模型；训练 5 epochs；
- 每个方法以 3 个随机种子运行，报告均值 ± 标准差（论文为 5 种子，CPU 预算下减为 3）；
- 评估指标（论文 5.2）：TR（复利累计收益）、SR、CR（E[r]/MDD，峰值序列含初始净值）、
  SoR（E[r]/下行波动），基于测试期逐日收益序列；单日权益损失以初始现金为下限
  （破产吸收态，日收益下限 -100%），避免做空极端行情下净值为负导致指标失真。

## 7. 基线与消融

| 类型 | 方法 | 说明 |
|---|---|---|
| 传统 | BAH / MV / TSM | 买入持有（杠杆净值触及 0 记破产吸收态）；均值回归（240-tick 均线）；时序动量（240-tick） |
| 预测 | MLP / GRU / LGBM | 回归未来 300-tick 收益，按符号满仓多 / 空 |
| RL | DQN | 3 动作（空 / 持 / 多）市价单、固定数量、MLP Q 网络 |
| 消融 | DS-NH / DS-NA | 去除 hindsight bonus / 去除波动率辅助任务 |

全部方法共用同一决策网格、撮合假设、费率、杠杆与日终强平规则。

## 8. 与论文的差异说明

1. **数据频率**：论文为 1 分钟 K 线 + 5 档 LOB；本项目为 3 秒快照 + 10 档 LOB，
   微观序列按 20 tick 抽样为 30 步以匹配回看窗口与 CPU 预算；
2. **标的类型**：论文为股指期货 / 国债期货（可多空、T+0）；本项目为 A 股个股，
   按用户确认保留多空双向 + 当日平仓的期货式仿真以忠实复现方法论；
3. **动作空间**：论文未公开离散档位取值，本项目取价格相对对手价 ±5 个最小价位、
   数量 9 档（相对中间价的固定档位在宽价差标的上无法穿价，见 3.3）；
4. **随机种子**：5 → 3（CPU 预算）；
5. **微观特征**：论文 20 维（5 档价量）；本项目 50 维（10 档价量 + 10 维微观结构增强）；
6. **杠杆**：论文 5 倍；本项目 1 倍。

## 9. 代码结构

```
deepscalper/
  config.py      全局配置（论文超参与 tick 适配参数）
  data.py        tick 数据加载、交易日过滤、7:1:2 切分
  features.py    微观 / 宏观特征与标签构建
  env.py         日内交易环境（撮合、奖励、净值）
  model.py       多模态编码器 + BDQ + 波动率头
  buffer.py      优先经验回放
  agent.py       BDQ 智能体（ε-greedy、TD 更新、辅助损失）
  dqn.py         DQN 基线
  baselines.py   BAH / MV / TSM / MLP / GRU / LGBM
  metrics.py     TR / SR / CR / SoR
  train.py       训练与贪心评估流程
scripts/
  run_all.py     并行实验运行器（幂等、断点续跑）
  summarize.py   结果汇总
  smoke_test.py  冒烟测试
docs/design.md   本文档
results/         实验输出（每作业一个 JSON + summary.csv）
```
